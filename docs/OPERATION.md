# 운영 가이드 (OPERATION.md)

## 월별 탭 추가

원본 시트에 새 월 탭(예: "4월", "5월")을 추가하면, 앱에서 **자동으로 인식**됩니다.

### 새 월 탭 추가 시 주의사항
1. 시트 이름은 **"N월"** 형식 (예: "4월", "5월")
2. **헤더 구조**(1~2행)가 기존 월과 동일해야 합니다
3. 데이터는 **3행부터** 시작
4. 앱 상단의 월 선택 드롭다운에 자동 추가됨

### 사감명령부 추가
- 시트 이름: **"N월 사감명령부"** (예: "4월 사감명령부")
- 기존 포맷과 동일하게 생성

## 벌점 항목 업데이트

### APP_DB 시트에서 직접 수정
1. APP_DB 스프레드시트 열기
2. **APP_벌점항목** 탭 선택
3. 행 추가/수정/삭제 가능

| 컬럼 | 설명 | 예시 |
|------|------|------|
| A: 항목명 | 벌점 명칭 | 자기주도적학습 불참 |
| B: 벌점 | 점수 (즉시퇴사=0) | 5 |
| C: 설명 | 상세 설명 | 야자 시간별 벌점 부여 |
| D: 카테고리 | 분류 | 학습 |

## 문자 템플릿 수정

### APP_DB > APP_문자템플릿 탭

사용 가능한 변수:
- `{이름}` — 학생 이름
- `{날짜}` — 오늘 날짜
- `{귀사시간}` — 귀사 예정 시간 (외출 시)

## 학생 연락처 관리

### 방법 1: 앱에서 개별 등록
학생 상세 화면 > **연락처 등록** 버튼

### 방법 2: APP_DB에서 일괄 입력
APP_DB > **APP_학생연락처** 탭에서 직접 입력

| 학번 | 학생명 | 학생전화 | 학부모전화 |
|------|--------|----------|-----------|
| 10101 | 홍길동 | 010-1234-5678 | 010-8765-4321 |

## 학기 초기화

학기가 바뀔 때:
1. APP_DB > **APP_벌점로그** 의 이전 학기 데이터를 백업(다른 시트로 복사)
2. 필요 시 **APP_외출외박로그** 도 백업
3. **원본 시트**의 새 학기 월별 탭 생성
4. 앱은 자동으로 새 월 탭을 인식

> ※ 1학기 동안 벌점 유지, 학기별로 벌점 갱신 (강경고 규정)
