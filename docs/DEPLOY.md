# 배포 가이드 (DEPLOY.md)

## 사전 준비

1. **구글 계정** — Google Workspace 또는 일반 구글 계정
2. **구글시트** — "2026 기숙사생 외출 및 외박 관리" (이미 보유)

> ✅ **A안 채택**: 별도 시트 생성 불필요! 기존 시트 1개만 사용합니다.

---

## 1단계: 시트 ID 확인

1. **"2026 기숙사생 외출 및 외박 관리"** 구글시트 열기
2. URL에서 **시트 ID** 복사:
   ```
   https://docs.google.com/spreadsheets/d/여기가_시트ID/edit
   ```
   → `여기가_시트ID` 부분만 복사

---

## 2단계: Apps Script 프로젝트 생성

1. [Google Apps Script](https://script.google.com) 에서 **새 프로젝트** 생성
2. 프로젝트 이름: **"기숙사 관리 웹앱"**

### 파일 추가

기존 `코드.gs` 파일을 삭제하고, 아래 파일들을 순서대로 생성:

| 파일명 | 타입 | 설명 |
|--------|------|------|
| `Code.gs` | 스크립트 | 메인 백엔드 (API 전체) |
| `Setup.gs` | 스크립트 | APP 탭 초기화 |
| `Index.html` | HTML | SPA 메인 HTML |
| `Stylesheet.html` | HTML | CSS 스타일 |
| `JavaScript.html` | HTML | 클라이언트 JS |

> 각 파일의 전체 내용을 이 프로젝트의 해당 파일에서 복사하여 붙여넣기

### appsscript.json 수정

1. 왼쪽 패널에서 ⚙️ **프로젝트 설정** 클릭
2. **"appscript.json" 매니페스트 파일을 에디터에 표시** 체크
3. `appsscript.json` 파일을 열고 이 프로젝트의 내용으로 교체

---

## 3단계: 스크립트 속성 설정

1. ⚙️ **프로젝트 설정** > **스크립트 속성** 섹션
2. 속성 **1개만** 추가:

| 속성 | 값 |
|------|-----|
| `SHEET_ID` | 1단계에서 복사한 시트 ID |

---

## 4단계: APP 탭 초기화

1. 에디터에서 `Setup.gs` 파일 열기
2. 함수 선택: **`setupAppDb`**
3. ▶️ **실행** 클릭
4. 권한 승인 (최초 1회)
5. **실행 로그**에서 "✅ APP_DB 초기화 완료!" 확인

> 이 단계를 실행하면 기존 시트에 `APP_외출외박로그`, `APP_벌점로그` 등의 탭이 자동 추가됩니다.
> 기존 "3월", "4월" 등의 원본 탭에는 전혀 영향 없습니다.

---

## 5단계: 웹앱 배포

1. 오른쪽 상단 **배포** > **새 배포**
2. 설정:
   - **유형**: 웹 앱
   - **설명**: 기숙사 관리 시스템 v1.0
   - **실행 권한**: 나(배포자)
   - **액세스 권한**: Google 계정이 있는 모든 사용자
3. **배포** 클릭
4. 생성된 **웹 앱 URL** 복사 — 이것이 앱 접속 주소!

---

## 6단계: 모바일 홈 화면 추가 (선택)

### Android (Chrome)
1. 웹 앱 URL을 Chrome에서 열기
2. 오른쪽 상단 ⋮ 메뉴 > **홈 화면에 추가**

### iOS (Safari)
1. 웹 앱 URL을 Safari에서 열기
2. 하단 공유 버튼 > **홈 화면에 추가**

---

## 업데이트 배포

코드 수정 후:
1. **배포** > **배포 관리** > 연필 아이콘 클릭
2. **버전**: 새 버전
3. **배포** 클릭
