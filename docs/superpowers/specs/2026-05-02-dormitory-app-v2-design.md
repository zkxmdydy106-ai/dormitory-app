## 1. 아키텍처 전환 (GAS → GitHub Pages + GAS API)

### 현재 구조
- Google Apps Script 웹앱 단일 배포
- `google.script.run`으로 서버 함수 직접 호출
- 코드 수정 시 GAS 재배포 필요 (URL 변경 없이도 번거로움)
- 첫 로딩 5~8초 (GAS 콜드스타트 + HTML 렌더링)

### 목표 구조
- **프론트엔드:** GitHub Pages (`index.html`, `style.css`, `app.js`)
  - GitHub에 push하면 즉시 자동 반영 (선생님들 URL 재공유 불필요)
  - CDN에서 즉시 로드 → 첫 화면 1초 미만
- **백엔드:** GAS를 순수 JSON API로 전환
  - `doGet(e)` → JSON 응답 반환
  - `doPost(e)` → 쓰기 작업 처리
  - `google.script.run` → `fetch(GAS_API_URL)` 로 교체
  - 구글 시트 연동 로직(Code.gs) 완전 유지

### GAS API 설계
```
GET  ?action=init&month=5월          → initApp 데이터
GET  ?action=studentList&month=5월   → 학생 목록
GET  ?action=penaltyItems            → 벌점 항목
POST action=toggleOutStay            → 외출/외박 토글
POST action=addPenalty               → 벌점 부여
POST action=addSuggestion            → 건의사항 작성
POST action=saveSetting              → 설정 저장
... (기존 모든 함수 대응)
```

CORS 허용 헤더 추가 필요 (`Access-Control-Allow-Origin: *`)

## 2. 버그 수정

### 벌점 이중계산 버그 (Critical)

**원인:** `getAppMonthlyData()` 내에서 두 경로로 초과 벌점이 합산됨
1. `checkAndApplyOverPenalty()` → `APP_벌점로그`에 "외출 초과" 항목 추가
2. `getAppMonthlyData()` → `appPenalty`(벌점 로그 합계)에 위 항목 포함됨
3. `getAppMonthlyData()` → `outOverPenalty = (appOutCount - maxOut) * overPenalty` 별도 계산 후 추가

결과: 초과 벌점이 `appPenalty`에 한 번 + `outOverPenalty`로 한 번 = **2배**

**수정:** `getAppMonthlyData()`에서 `outOverPenalty`, `stayOverPenalty` 별도 계산 제거.  
`checkAndApplyOverPenalty()`가 항상 벌점 로그를 정확히 유지하므로 `appPenalty`만 사용:
```
calculatedTotalPenalty = student.totalPenalty + appPenalty
```

## 3. 외박 → 외출 변환 기능

### 요구사항
- 학생 상세 화면에서 "외박을 외출로 변환하여 사용" 버튼 제공
- 변환 기록은 `APP_외출외박로그`에 `type: "외박(외출전환)"` 으로 저장
- 변환된 항목은 **외출 횟수에 카운트** (외박 횟수에는 미포함)
- 변환된 항목이 포함된 외출 횟수가 최대치 초과해도 **벌점 미부과**
- 학생 카드/상세에 "외출 N (전환 X포함)" 형태로 표시
- 변환 취소도 가능 (토글 방식)

### 데이터 모델
`APP_외출외박로그` 새 type 값: `"외박(외출전환)"`
- 외출 횟수 계산 시 포함
- 외박 횟수 계산 시 미포함
- 초과 벌점 계산 시 제외 (별도 플래그로 처리)

## 4. 사감 근무 캘린더

### 요구사항
- 기존 교사 선택 드롭다운 + 교사별 근무일 목록 **그대로 유지**
- 새로 캘린더 뷰 추가 (월 달력)
- 날짜 셀 클릭 → 해당일 사감 이름 표시 (툴팁 또는 인라인)
- 오늘 날짜 강조 표시
- 근무 있는 날짜는 점(dot) 또는 배경색으로 표시

### 구현
- 순수 HTML/CSS/JS로 달력 렌더링 (외부 라이브러리 불필요)
- `APP.dutyData` 기존 데이터 재활용 (서버 추가 호출 없음)
- 사감 페이지 레이아웃: 상단 캘린더 / 하단 교사 선택 드롭다운

## 5. 특별활동 표시 (학원/악기/야간방과후/오케스트라)

### 요구사항
- 특정 학생이 특정 요일 특정 시간에 외부 활동 예정임을 사전 등록
- 등록된 학생은 해당 요일에 자습 자리에 없어도 이유 확인 가능
- 사감 선생님이 학생 목록에서 바로 확인 가능

### 데이터 구조 (`APP_특별활동` 시트)
| 학번 | 이름 | 호실 | 활동종류 | 요일 | 시작시간 | 종료시간 | 비고 |
|------|------|------|----------|------|----------|----------|------|
| 2024042 | 이수아 | 101 | 학원 | 월,수,금 | 17:30 | 20:00 | 수학학원 |
| 2024001 | 김민준 | 201 | 오케스트라 | 화,목 | 16:00 | 18:30 | |

### UI
- 학생 카드에 오늘 활동 있으면 뱃지 표시: `🏫 학원 17:30`
- 학생 상세 화면에 이번주 활동 스케줄 섹션 추가
- 설정 화면에서 특별활동 등록/수정/삭제 관리

## 6. UI/아이콘 업그레이드

### 방향
- 현재 전체 디자인 레이아웃/색상 **유지**
- 이모지 → 커스텀 SVG 아이콘으로 전부 교체
- 네비게이션 바 5개 아이콘 교체 (학생, 누가기록, 건의, 사감, 설정)
- 학생 카드 내 아이콘 (🏠→, 📝→ 등)
- 외출/외박 토글 버튼 아이콘
- 버튼 아이콘 전반

### 남녀 색상 구분
- **여학생 (1xx호, 101~199):** 카드 왼쪽 테두리 + 아바타 배경 → 옅은 핑크 계열 (`#FDE7EF`, `#F472B6`)
- **남학생 (2xx호, 201~299):** 기존 파란 계열 유지 (`#DBEAFE`, `#60A5FA`)
- 판별 로직: `room` 첫 글자 === '1' → 여학생, '2' → 남학생
