# 변경 이력 (CHANGELOG.md)

## v1.0.0 (2026-03-05)

### 최초 릴리스

#### 핵심 기능
- **학생 리스트/검색** — 원본 시트 월별 탭에서 학생 목록 로드, 호실/학번/이름 검색
- **학생 상세** — 외출/외박 횟수, 벌점, 징계 현황 표시
- **외출/외박 토글** — 오늘 날짜 외출/외박 기록 ON/OFF, 월 2회 초과 시 벌점 자동 부과 (1회당 5점)
- **벌점 부여** — 실제 강경고 기준표 기반 벌점 항목 선택 및 부여
- **징계 자동 판단** — 5점 반성문 / 8점 봉사 / 12점 학부모상담 / 15점 임시퇴사 / 20점 퇴사
- **연락 기능** — 전화걸기(tel:), 문자보내기(sms:) 딥링크, 문자 템플릿 자동 삽입
- **누가기록** — 원본 + 앱 누가기록 통합 조회, 수동 추가
- **교사 건의사항** — 건의 작성/조회/상태관리
- **사감 근무 조회** — 교사별 필터링
- **감사 로그** — 모든 변경 자동 기록

#### 데이터 설계
- **B안 채택** — 별도 APP_DB 스프레드시트에 정규화 로그 저장
- **원본 동기화** — SYNC_TO_ORIGINAL=ON 시 원본 시트 E/I/F/J/M/N열 자동 업데이트

#### 기술 스택
- Google Apps Script (Web App)
- Pure.css + 커스텀 CSS
- google.script.run API
- SPA 아키텍처

#### 인증
- 구글 계정 로그인만으로 바로 접근 (PIN 없음)
